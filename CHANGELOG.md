# Changes

Each version's section is shown in the app as "What's new" when it is offered as an update.

## 0.2.0
- Review screen: a floating brightness & contrast panel (press I), like Fiji's: histogram with draggable limits, brightness, contrast, gamma, colours (grey, green, fire, inverted), Auto and Reset. It changes only how the image looks.
- KidneyCyst now updates itself: when a new version is published, the start page offers "Update now". Your runs and reviews are kept.
- When detection runs on another computer, KidneyCyst says if the copy there is a different version and offers to update it.

## 0.1.0
- First version given to users: detection, review, report, Excel table, QuPath round trip, beta grade and elbow length.
