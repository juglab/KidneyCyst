Quick start

  1. New analysis. On the start page, choose a folder containing 2-D TIFF images or z-projections, with GFP in the first channel. Subfolders are included. The run's own page opens; every run you analyse is listed on the start page under Your runs.
  2. Run detection. KidneyCyst generates candidate pronephros outlines and calculates their areas in µm² using the recorded pixel size.
  3. Review outlines. Accept an outline with A, mark no kidney visible with N, or mark an image as unassessable with C. Use the brush or lasso to edit an outline, then press A to save and advance.
  4. Open results. The Excel table and report are updated after each review decision. Select Open Excel table to view the measurements.

Results are saved beside the input folder in <your folder>_kidneycyst. Source images are not modified.

Processing time depends on the device and image size. Fast mode uses one model instead of the three-model ensemble.

Sample identifiers are extracted from Opera/Harmony filenames, such as … Well B07, Field 4.tif. Folder names containing Run5 or Plate2 provide run and plate identifiers.

Pixel size is read from TIFF metadata. If unavailable, the app uses 1.19595 µm/pixel and displays a calibration warning. Verify this value before interpreting physical areas; a different value can be entered before running detection.

Model & validation

KidneyCyst segments the pronephros and measures its area. This version does not detect individual cysts or measure cyst features.

ModelKC009-p512-250ep-gfp
MethodnnU-Net v2, trained in 2-D on 512 × 512 pixel patches for 250 epochs. Inference uses sliding windows and mirroring. The default prediction averages three models, each trained with one experimental run held out.
Training imagesGFP-channel z-projections of zebrafish larvae at 2 days post-fertilisation, acquired on an Opera Phenix at 1080 × 1080 pixels and 1.196 µm/pixel. Preprocessing uses fixed intensity scaling without per-image normalisation.
Training dataset686 images from three experimental runs (Runs 2–4), annotated in QuPath by Nikita Toločkovs (Institut Imagine). Blurred images, images without outlines and images with uncertain grades were excluded.
AreaArea is calculated from mask pixel count and pixel area, then divided by 1.02. This is an empirical correction measured on the training data (median ratio of raster-mask pixels to QuPath polygon area); it is not a general conversion.

  • Single model vs. default: these numbers are for single held-out models. The default three-model average has not been validated separately on held-out runs.
  • Images graded with cysts is an evaluation subgroup (images whose manual grade includes a cyst). It does not mean that individual cysts are detected.
  • Baseline: assigning every image the median area of the training runs (also leave-one-run-out) gives an error within 20% for 81% of images.
  • An independent blinded reader study comparing model-generated and manual outlines is in progress.

Limitations

  • All training annotations were produced by one annotator. Predictions may reflect that annotator’s boundary conventions.
  • Performance varies between experimental runs. For Run 3, 89% of area estimates were within 10% of the reference measurement.
  • Performance has not been evaluated on other developmental stages, microscopes, magnifications or reporter lines. Validate predictions before using measurements from these inputs.
  • Outlines that reach the image boundary are flagged. Their areas include only the region within the image.

Grade and elbow-to-elbow length (beta)

Beta: not yet validated against manual grading or manual elbow measurements. Use these values to explore, not to report.

  • Grade (beta): normal, unfused or cyst, with its probability, from the shape and GFP signal of the model outline. Grades below 70% probability are marked uncertain (column flag_grade_uncertain; this flag does not change which images are listed as flagged for review).
  • Elbow-to-elbow (beta): two candidate definitions from the model outline: straight, the longest straight line across the outline, and midline, the length along the outline's centre line. Elbow length is not annotated in the training data.
  • Your measurements: in the review screen, Measure elbow (M) records points along the tubule from elbow to elbow, and Your grade records your grade. Both are saved with your name and the time, kept when detection is run again, and are the data used to validate the beta values.
  • Held-out accuracy of the beta grade: 62% balanced accuracy over the 3 grades (leave-one-run-out, 686 images; cyst vs normal AUC 0.83). On images marked confident (about 1 in 3): 75%. Use it to sort images for review, not as a grade.

Data & network

  • Image analysis runs locally. The interface is served at 127.0.0.1 on this computer; KidneyCyst does not upload images, outlines or results.
  • An internet connection is required during installation to download Python, PyTorch and dependencies. Optional QuPath integration downloads paquo and JPype and, if needed, QuPath from GitHub.
  • The application does not perform update checks or send telemetry or crash reports. Model weights are bundled with the installation.
  • Analysis results are saved in the _kidneycyst folder beside the input folder. Application logs are saved in the installation folder.

Common problems

No TIFF images foundSelect a folder containing .tif or .tiff images. Subfolders are searched automatically.
Slow processingCheck the processing device on the home screen. CPU processing is slower. Fast mode reduces the number of models used for prediction.
Excel table not updatedClose results.xlsx in Excel. KidneyCyst retries writing it after the next review decision. Check the CSV export for the latest successfully saved results.
Interface does not openRelaunch KidneyCyst from its application icon. The local server stops five minutes after the last application tab is closed.
